PART 1 · DAY 1

기술스택 10개를 하나씩 설명하고 실습합니다

각 기술이 담당하는 역할을 이해하는 것이 1일차의 목표입니다. 로컬·Office는 Python·VBA가, 화면은 HTML·CSS·JavaScript가, 조회·업무처리·생성은 세 가지 API가 담당합니다.

Python
파일·폴더·엑셀을 다루는 로컬 자동화의 기본기
VBA
사내 보안 환경에서도 돌아가는 Office 자동화
HTML · CSS
업무도구의 구조와 디자인 — 화면을 만드는 법
JavaScript
화면에 기능을 연결하고 움직이게 하는 언어
데이터 API
공공데이터·환율·공휴일 등 외부 데이터 조회
기능 API
지도·지오코딩·알림 등 업무처리 기능 호출
AI API
생성형 AI를 내 업무도구 안으로 — LLM 연동
DB · SQL
데이터를 쌓고 불러오는 저장소의 기본 구조
SLM
보안 환경을 위한 소형 로컬 모델 활용

PART 2 · DAY 2

수강생이 요청한 프로젝트를 그 자리에서 구현합니다

예제 따라하기가 아니라, 참가자가 가져온 실제 업무 문제에 필요한 기술 조합과 구성도를 함께 설계하고 완성합니다. 아래는 지난 기수(2026.09) 수강생들이 이틀 안에 직접 만들어 배포까지 마친 결과물입니다.

간선구간 유류비·운송원가 자동 계산기 (TMS)
터미널 주소 지오코딩과 도로 주행경로 분석으로 차종(톤급)별 유류비·통행료·운송원가를 자동 산출, 지도 시각화와 CSV 정산서 다운로드까지.
글로벌 해외송금 도래일(Settlement Date) 계산기
송금국·수취국 양국 은행의 공휴일·주말을 대조해 실제 계좌 입금 완료일을 산출. 공휴일 API 연동.
전 세계 국가별 공휴일 기반 통관·하역 영업일 계산
국가별 공휴일 정보를 불러와 통관·하역이 멈추는 날을 제외한 실제 영업일을 계산.
거점 입지 최적화 도구
물류 거점 후보지를 데이터 기반으로 비교·시각화하는 입지 분석 도구.
LCL 화물 권역 그룹핑 지도
복수의 우편번호를 입력하면 지도에 마커를 찍고, 반경 50km 이내 화물을 같은 색상 그룹으로 묶어 컨테이너 적재 효율화.
물류센터·터미널 현장 체크인 시스템
차량·기사 도착 확인과 현장 운영을 디지털로 전환하는 체크인 도구.

위 결과물은 전원 코딩 경험이 없던 참가자들이 교육 이틀 안에 실제 서비스 URL로 배포한 프로젝트들입니다. 수료 시 전원이 자신의 업무 프로젝트 1개를 배포 완료한 상태로 돌아갑니다.
